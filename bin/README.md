# Binários / Binaries

Este diretório contém os arquivos executáveis do SysFinanceiro.
This directory contains the SysFinanceiro executable files.

## Estrutura / Structure

- `sysfinanceiro` - Executável principal (Linux/Unix)
- `sysfinanceiro.exe` - Executável principal (Windows)
- `sysfinanceiro-service` - Serviço em background (Linux/Unix)
- `sysfinanceiro-service.exe` - Serviço em background (Windows)

## Uso / Usage

Após a instalação, os executáveis estarão disponíveis no PATH do sistema.
After installation, the executables will be available in the system PATH.
