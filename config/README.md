# Configurações / Configuration

Este diretório contém os arquivos de configuração do SysFinanceiro.
This directory contains the SysFinanceiro configuration files.

## Arquivos / Files

- `config.json` - Configuração principal do sistema
- `database.json` - Configuração do banco de dados
- `security.json` - Configurações de segurança
- `logging.json` - Configuração de logs

## Localização após instalação / Location after installation

### Linux/Unix
- Sistema: `/etc/sysfinanceiro/`
- Usuário: `~/.config/sysfinanceiro/`

### Windows
- Sistema: `%ProgramData%\SysFinanceiro\`
- Usuário: `%APPDATA%\SysFinanceiro\`
