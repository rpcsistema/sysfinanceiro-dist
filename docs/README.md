# Documentação / Documentation

## SysFinanceiro - Sistema Financeiro

### Visão Geral / Overview

O SysFinanceiro é um sistema completo de gestão financeira desenvolvido para atender às necessidades de pequenas e médias empresas.

SysFinanceiro is a complete financial management system developed to meet the needs of small and medium enterprises.

### Funcionalidades / Features

- ✅ Controle de contas a pagar e receber
- ✅ Fluxo de caixa
- ✅ Relatórios financeiros
- ✅ Conciliação bancária
- ✅ Gestão de fornecedores e clientes
- ✅ Controle de centro de custos

### Instalação / Installation

Consulte o arquivo README.md na raiz do projeto para instruções de instalação.
See the README.md file in the project root for installation instructions.

### Configuração / Configuration

1. Edite o arquivo `config/config.json` conforme suas necessidades
2. Configure a conexão com o banco de dados
3. Defina as configurações de segurança
4. Execute o sistema
